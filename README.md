# Мій день — персональний планувальник (PWA для iPhone)

Мобільний вебзастосунок у стилі iOS: календар, завдання, фокус-таймер, звички, цілі, щоденник, ранковий і вечірній огляд,
Smart Planner та AI-помічник. Працює офлайн, зберігає дані в IndexedDB на самому телефоні, встановлюється на головний екран.

Стек: React 18 · TypeScript · Vite · Tailwind CSS · lucide-react · IndexedDB · Service Worker. Без зайвих залежностей
(дати, графіки, роутер, сховище — власні, невеликі модулі).

---

## 1. Запуск на комп’ютері

Потрібен Node.js 18+ (перевірено на Node 26).

```bash
cd day-planner
npm install
npm run dev          # розробка: http://localhost:5173
npm test             # 33 автоматичні тести логіки
npm run build        # production-збірка у папку dist/
npm run preview      # перегляд збірки: http://localhost:4173 (тут працює Service Worker)
```

> **Windows із Smart App Control / Application Control.** Нативний пакет `rollup` може блокуватися політикою Windows.
> У `package.json` вже стоїть заміна на WASM-збірку (`overrides → @rollup/wasm-node`), тому все працює без додаткових дій.

Щоб відкрити dev-версію на iPhone в одній Wi-Fi-мережі: `npm run dev`, потім у Safari `http://IP-комп’ютера:5173`.
Це лише для перегляду: без HTTPS Service Worker, офлайн і push **не працюють**.

## 2. Публікація (потрібен HTTPS) — усе безкоштовно

iPhone дозволяє Service Worker і push лише на HTTPS-сайтах. Найпростіше — розмістити готову папку `dist/`:

### Варіант A — Netlify Drop (найшвидше, без акаунту Git)
1. `npm run build`
2. Відкрийте <https://app.netlify.com/drop> і перетягніть туди папку `dist` (або файл `release/day-planner-dist.zip`, розпакувавши його).
3. Отримаєте адресу виду `https://назва.netlify.app` — це і є ваш застосунок.

### Варіант B — GitHub Pages
1. Створіть репозиторій, покладіть вміст папки `day-planner` у його корінь і запуште.
2. Settings → Pages → Source: **GitHub Actions**. Файл `.github/workflows/deploy.yml` уже є — сайт збирається й публікується при кожному push у `main`.
3. Адреса: `https://ВАШ_ЛОГІН.github.io/НАЗВА_РЕПО/` (застосунок використовує відносні шляхи, тож працює у підпапці).

### Варіант C — Cloudflare Pages / Vercel
Підключіть репозиторій: Build command `npm run build`, Output directory `dist`.

## 3. Встановлення на iPhone

1. Відкрийте адресу вашого сайту **в Safari** (не в Chrome).
2. Натисніть **«Поділитися»** (квадрат зі стрілкою).
3. Оберіть **«На початковий екран»**.
4. Натисніть **«Додати»**.
5. Запускайте застосунок **з іконки на головному екрані** — він відкриється без адресного рядка (standalone).

Ця ж інструкція є в самому застосунку: **Профіль → Встановлення на iPhone**.

## 4. Нагадування та Web Push (необов’язково, потрібен сервер)

Що важливо знати про iOS:

* Без сервера нагадування спрацьовують, **лише поки застосунок відкрито** (iOS призупиняє JavaScript у фоні).
* Web Push на iPhone працює з **iOS 16.4+**, лише для застосунку, **доданого на головний екран**, і лише після вашої згоди.
* Для push потрібен сервер, що надсилає повідомлення. Він є в папці `server/` (Node.js, без платних сервісів).

Запуск сервера:

```bash
cd server
npm install
npm start            # порт 8787; ключі VAPID створюються автоматично (vapid.json)
```

Змінні середовища (необов’язково): `PORT`, `ALLOWED_ORIGIN` (адреса вашого PWA — **задайте в продакшні**),
`VAPID_CONTACT` (mailto:ваш@email), `DATA_FILE`.

Сервер має бути доступний по **HTTPS**. Безкоштовні способи:
* залишити його на своєму ПК/міні-сервері й відкрити назовні через **Cloudflare Tunnel** (`cloudflared tunnel --url http://localhost:8787`);
* розмістити на безкоштовному хостингу Node.js (Render, Fly.io тощо — умови їхніх безкоштовних планів змінюються, перевіряйте самі).

Підключення: у застосунку **Налаштування → Сповіщення →** вставте адресу сервера → **Увімкнути push** → дозвольте сповіщення →
**Тестовий push**. Застосунок передає серверу розклад нагадувань на 7 днів уперед і оновлює його після кожної зміни завдань.

## 5. AI-помічник

* **За замовчуванням** працює локальний помічник (без інтернету й без оплати): розбирає фрази на кшталт
  «Завтра о 15:00 хочу навчатися дві години, а ввечері залишити час для відпочинку», будує розклад, аналізує навантаження та продуктивність.
* **Хмарний AI** — необов’язково й **платно** (API Anthropic): задайте на сервері змінну `ANTHROPIC_API_KEY` (і за потреби `AI_MODEL`),
  потім у застосунку: Налаштування → AI → увімкнути й вказати адресу сервера. Ключ зберігається **лише на сервері** й ніколи не потрапляє в клієнт.
* Будь-які зміни розкладу від AI та Smart Planner застосовуються **тільки після вашого підтвердження**.

## 6. Дані та резервні копії

* Усе зберігається локально в IndexedDB (автозбереження, відновлення після перезапуску).
* **Профіль → Резервні копії**: експорт/імпорт JSON із перевіркою файлу, режими «Об’єднати»/«Замінити», автоматичний знімок раз на добу
  та перед кожним імпортом/очищенням (захист від випадкового перезапису), відновлення зі знімка.
* Записи мають `updatedAt` і стабільні `id` — основа для майбутньої синхронізації між пристроями (самої синхронізації ще немає).
* Якщо ви не встановили застосунок на головний екран, а лише відкриваєте сайт у Safari, iOS може очистити дані сайту, якщо ним довго не користуватися. Встановлена PWA від цього захищена краще, але **копії все одно робіть**.

## 7. Структура проєкту

```
src/lib/      логіка без UI: store (IndexedDB), nlp (розбір фраз), planner (Smart Planner), score (оцінка дня, серії),
              stats, achievements, personalize, reminders, push, backup, ai, timer, sound, i18n
src/ui/       компоненти: kit, Host (листи/сторінки/таб-бар), uiStore (навігація), charts, TaskRow
src/screens/  екрани: Home, Calendar, Tasks, Focus, Profile, Morning, Evening, SmartPlanner, Assistant, Habits, Goals,
              Journal, Stats, Templates, Countdowns, Achievements, Settings, Install, BackupPage, Insights …
src/sw.template.js   Service Worker (кеш для офлайну + push); версію й список файлів підставляє vite.config.ts
public/       manifest, іконки (npm run icons перегенерує їх із icon.svg)
server/       необов’язковий сервер: Web Push + проксі до AI
tests/        vitest: nlp, повторення, конфлікти, Smart Planner, оцінка дня, серії, нагадування, резервні копії
```

## 8. Чесно про обмеження iOS

| Що | Статус |
|---|---|
| Іконка на головному екрані, повний екран, тема, safe area | ✅ |
| Офлайн-режим | ✅ (кеш Service Worker) |
| Нагадування й звуки, поки застосунок відкрито | ✅ |
| Web Push у закритому застосунку | ⚠️ iOS 16.4+, лише з головного екрана, потрібен ваш сервер |
| Власний звук push-повідомлень | ❌ iOS використовує системний звук |
| Таймер/звук у фоні без push | ❌ iOS призупиняє вебзастосунок (таймер рахує за годинником, тож після повернення показує правильний час) |
| Віджети iOS, Dynamic Island, Live Activities | ❌ лише нативний застосунок; у PWA є альтернативи всередині (екран «Головна», повноекранний Focus Mode) |
| Вібрація | ❌ iOS не дає її вебу |
| Звуки при вимкненому перемикачі «Без звуку» | ❌ вони підпорядковуються цьому перемикачу |

## 9. Стан тестування

Автоматично перевірено (у цьому середовищі, у браузері на базі Chromium з емуляцією екрана 375×812): 33 unit-тести логіки; типізація `tsc`;
збірка; створення завдань фразою, через редактор (створення, редагування, валідація, видалення серії), календар (день/тиждень/місяць,
перетягування й зміна тривалості мишею), збереження після перезавантаження, експорт/імпорт/відновлення зі знімка, фокус-таймер,
усі екрани з даними (без помилок), офлайн-режим (Service Worker віддає застосунок при вимкненому сервері), ендпоінти push-сервера.

**Не перевірено на реальному iPhone/Safari** (немає пристрою): жести дотику (довге натискання й перетягування), поведінку клавіатури,
встановлення через «Поділитися», standalone-режим, Web Push на iOS, звук. Це потрібно пройти вам один раз після публікації —
якщо щось поводиться інакше, напишіть, що саме.
